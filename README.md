# Guion · Sistema de Gestión Cielo Abierto

Página de presentador para el speech de 8 minutos de la carpeta de Práctica Profesionalizante I ("Sistema de Gestión Cielo Abierto", división 31N).

Es un solo `index.html`, sin build y sin dependencias: se abre con doble clic y funciona sin internet. Los cuatro diagramas (hechos con archify) están incrustados en la página.

## Uso

| Tecla | Acción |
|---|---|
| Espacio | Empezar o pausar |
| ← → | Parte anterior o siguiente |
| ↑ ↓ | Párrafo anterior o siguiente |
| + − | Tamaño del texto |
| F | Pantalla completa |
| R (dos veces) | Reiniciar los cronómetros |

Vistas: **Presentar** (una parte por vez, con cronómetro total y por parte), **Guion completo** y **Práctica** (tiempo medido contra el planificado, con ensayos guardados). La parte y el tiempo se guardan en el navegador, así que una recarga no pierde el avance.

## Archivos

- `index.html`: la página.
- `PRODUCT.md` y `DESIGN.md`: contexto del producto y sistema visual.
- `.impeccable/`: decisiones de diseño (dirección elegida y tokens).
